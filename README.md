# David J. Najera — NFC Professional Contact Card

This folder is ready to publish with GitHub Pages.

## Intended live address

https://everforgeinc.github.io/

## Publish

1. In GitHub, create a new PUBLIC repository named exactly:
   `EverForgeInc.github.io`
2. Upload all files from this folder to the root of the repository.
3. Open repository **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select the `main` branch and `/ (root)`, then Save.
6. After GitHub publishes the site, test:
   `https://everforgeinc.github.io/`
7. Program that URL into your NFC tag as a URL/URI record.

## Files

- `index.html` — the professional landing page
- `david-najera.vcf` — downloadable contact card
- `qr-everforgeinc-pages.png` — QR code for the GitHub Pages URL
